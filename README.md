## CRUD Application (Node.js, Express, MongoDB)

A full-stack CRUD application built with Express.js and EJS, featuring separate user and admin flows with session-based authentication.

### Features
- User & Admin route separation
- Session-based authentication with flash messages for user feedback
- MongoDB integration via Mongoose
- Server-side rendering with EJS templating
- Request logging with Morgan

### Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Templating:** EJS
- **Auth/Session:** express-session, connect-flash
- **Other:** dotenv, uuid, nocache
